# Behat Steps documentation

This directory holds the source of the [Behat Steps documentation site](https://behat-steps.drevops.com), built with [Docusaurus](https://docusaurus.io/). The pages live in `content/`.

```bash
npm install                  # Install the dependencies
npm start                    # Serve the site locally, reloading on every change
npm run build                # Build the static site into build/
npm test                     # Run the unit tests and the spell check
npm run test:accessibility   # Check the built site for accessibility issues
```

See [Documentation](content/contributing/documentation.md) for how the site is built, checked and published, and which pages are generated.
